# ASP.NET Core Framework Post Mortem

Let's talk about ASP.NET Core for a bit. In the Malaysian tech scene, ASP.NET Core is one of the most popular frameworks for backend development alongside Spring and whatever NodeJS spits out. Learning ASP.NET Core would be very beneficial should a person seeks employment in Malaysia. In fact, getting friendly with Microslop's whole ecosystem would immensely increase your likelihood of getting hired in Malaysia since a lot of Malaysian companies prefer Azure cloud services over Google or Amazon's. That being said:

I don't like .NET Core. It feels like it wants to be opinioniated only to give up half-way through. It has features that it was to be done its way but not as predictable as you were to work on Laravel. I have no problem if the job requires me to use it but if I were to be given a chance, I'm very unlikely to pick ASP.NET Core as a framework to build a backend system with. I spent so much time setting up the boilerplates that I don't even recall its good points. 

One thing I can somewhat appreciate is that it comes with its own way of handling return responses. In Laravel, I wrote an `APIController` to fill in that shoe, ASP.NET Core abstracts that portion and everything is handled by `Microsoft.AspNetCore.Mvc` package.

Other that than, fuck ASP.NET Core. I hope I don't work this framework anytime in the future.
